# ИС «Деканат» (Вариант 7)

Автоматизированная информационная система учебного отдела: ведение нормативно-справочной информации (категории, дисциплины, учебные группы, преподаватели, студенты), составление расписания сессии, журнал успеваемости и формирование отчётных документов.

Это **полная версия с авторизацией по ролям**: вход по логину и паролю, состав таблиц и кнопок формируется по роли пользователя. Упрощённая версия без авторизации находится в ветке **`ver1`**.

## Технологии

| Компонент | Описание |
|---|---|
| Интерфейс | Windows Forms (C#), .NET Framework 4.7.2, x64 |
| СУБД | Microsoft Access — файл `Деканат_Вариант7.accdb` |
| Доступ к данным | OleDb, провайдер `Microsoft.ACE.OLEDB.12.0` |
| Сборка | Visual Studio 2022 (MSBuild) |

## Требования

- Windows 10/11 (разрядность x64);
- .NET Framework 4.7.2 или выше;
- Microsoft Access Database Engine 2010/2016 (x64) — провайдер `Microsoft.ACE.OLEDB.12.0`;
- для сборки из исходников — Visual Studio 2022.

## Запуск

1. Клонировать репозиторий и переключиться на ветку `ver2`:
   ```
   git clone https://github.com/ВАШ_ЛОГИН/ИМЯ_РЕПО.git
   cd ИМЯ_РЕПО
   git checkout ver2
   ```
2. Открыть `WindowsFormsApp1.slnx` в Visual Studio и нажать **F5** (или собрать `Release|x64` и запустить `WindowsFormsApp1.exe` из `bin\x64\Release`).
3. Файл БД `Деканат_Вариант7.accdb` уже лежит в папке проекта и автоматически копируется в выходной каталог при сборке. Рабочей копией является файл в `bin\Debug` (параметр `|DataDirectory|`).
4. При первом запуске таблицы `tbl_Users` и `tbl_Journal` создаются в БД автоматически, вместе с предустановленными учётными записями.

## Учётные записи

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin` | Администратор |
| `metodist` | `1234` | Методист |
| `teacher` | `1234` | Преподаватель |
| `student` | `1234` | Студент |

## Права ролей

- **Администратор** — все таблицы, включая «Пользователи» (добавление и удаление учётных записей);
- **Методист** — ведение справочников, составление расписания сессии, отчёты, а также постановка, изменение и удаление оценок в журнале;
- **Преподаватель** — журнал успеваемости: поставить оценку, изменить оценку, изменение журнала; просмотр групп и расписания;
- **Студент** — просмотр групп, расписания сессии и журнала успеваемости (с фильтрами по группе, году и месяцу); изменение данных не предусмотрено.

## Отчёты

- «Списки студентов по группам» — по алфавиту или по среднему баллу, с разбиением на части по 30 человек;
- «Расписание группы»;
- «Длительность сессии» — суммарная трудоёмкость по группам.

## Структура базы данных

| Таблица | Назначение |
|---|---|
| `tbl_Categories` | категории студентов |
